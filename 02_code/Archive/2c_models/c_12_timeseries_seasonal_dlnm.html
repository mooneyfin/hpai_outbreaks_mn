Companion to the case-crossover in c_11, answering the question that design cannot.

A case-crossover matches each case to referents in the same cell within a few weeks, which throws away every between-season contrast by construction. It can only tell you whether a short-term deviation precedes an event. That matters here because 71% of Minnesota’s cases are in spring, so “why spring?” is a between-season question the matched design is blind to.

This model keeps the whole panel and adjusts for season explicitly instead: a cyclic RW2 over week-of-year absorbs the seasonal epidemic curve, an iid cell effect absorbs between-cell differences, and feedlot_count enters as the offset (only premises can have a spillover). Exposure effects are then identified from week-to-week deviations that survive the seasonal cycle — strictly more temporal signal than matching leaves behind.

Meteorology only — and why

No bird term goes in this model, and it must not. a_04_zone_bird_abundance_multistate only extracts eBird abundance for event zones, because that is all the case-crossover ever needs. Across the full grid the result is that waterfowl abundance is non-zero in exactly the 77 cells that had an outbreak and zero in all 1,484 others — those zeros are missing data, not low counts. Any model that compares outbreak cells against non-outbreak cells therefore gets a bird variable that is a perfect indicator of case-cell status, and “discovers” a spillover association by construction. An earlier version of this file included the bird term and returned RR 1.45 (1.38, 1.51) with a 411-point WAIC gap; that was entirely circular.

ERA5 covers every cell, so the meteorological terms have no such problem and this model is valid for them. The waterfowl question stays in c_11, where cases and controls are days inside the same event cell and bird data exists for both. Extending the eBird raster extraction to all cells would make a bird term legitimate here; until then it is left out.

Two other coverage limits worth knowing: feedlot_count is a Minnesota registration layer (1,561 MN cells, 37 in Wisconsin, zero elsewhere), so the offset confines this model to Minnesota.

2. Fit

cbs <- list(); cb_cols <- list()
dat <- data.frame(cases = wk$cases, E = wk$feedlots)
for (v in VARS) {
  X  <- as.matrix(wk[, paste0(v, "_Lag", 0:4), with = FALSE])
  cb <- dlnm::crossbasis(X, lag = c(0, 4), argvar = list(fun = "lin"),
                         arglag = list(fun = "ns", df = 2))
  colnames(cb) <- paste0("cb_", v, ".", colnames(cb))
  cbs[[v]] <- cb; cb_cols[[v]] <- colnames(cb)
  dat <- cbind(dat, as.data.frame(unclass(cb)))
}
dat$id_season <- wk$iso_week                              # cyclic seasonal curve
dat$id_space  <- as.integer(as.factor(wk$zone_id))        # cell-level differences
cbn <- unlist(cb_cols)

hyper.iid <- list(theta = list(prior = "pc.prec", param = c(1, 0.01)))
form <- paste0(
  "cases ~ 1 + offset(log(E)) + ",
  "f(id_season, model = 'rw2', hyper = hyper.iid, constr = TRUE, cyclic = TRUE) + ",
  "f(id_space,  model = 'iid', hyper = hyper.iid) + ",
  paste(cbn, collapse = " + "))

fit_ts <- INLA::inla(
  as.formula(form), data = dat, family = "poisson",
  control.fixed = list(correlation.matrix = TRUE,
    mean = as.list(setNames(rep(0, length(cbn)), cbn)),
    prec = as.list(setNames(rep(INLA_PREC_PRIMARY, length(cbn)), cbn)),
    prec.intercept = 0.001, mean.intercept = 0),
  control.compute = list(dic = TRUE, waic = TRUE, config = TRUE),
  control.inla = list(strategy = "simplified.laplace", int.strategy = "eb",
                      control.vb = list(enable = FALSE)),
  num.threads = 1)

3. Cumulative RR over the 0-4 wk lag window

# same contrast machinery as c_11: build the lag contrast by hand off the stored covariance
ts_cumulative <- function(fit, cbs, cb_cols, vars, step = 0.5) {
  V <- fit$misc$lincomb.derived.covariance.matrix
  data.table::rbindlist(lapply(vars, function(v) {
    idx <- match(cb_cols[[v]], fit$names.fixed)
    b   <- fit$summary.fixed[idx, "mean"]
    W   <- colSums(do.call(dlnm::onebasis, c(list(x = 0:4), attr(cbs[[v]], "arglag"))))
    cv  <- step * W
    lo  <- sum(cv * b)
    se  <- sqrt(as.numeric(t(cv) %*% V[idx, idx] %*% cv))
    data.table::data.table(Predictor = unname(INLA_LABELS[v]),
      RR = exp(lo), low = exp(lo - 1.96 * se), high = exp(lo + 1.96 * se))
  }))[, `RR (95% CrI)` := sprintf("%.2f (%.2f, %.2f)", RR, low, high)][]
}
res_ts <- ts_cumulative(fit_ts, cbs, cb_cols, VARS)
print(res_ts[, .(Predictor, `RR (95% CrI)`)])

alt <- function(extra, fam) {
  f <- INLA::inla(as.formula(paste0(
      "cases ~ 1 + offset(log(E)) + ",
      "f(id_season, model='rw2', hyper=hyper.iid, constr=TRUE, cyclic=TRUE) + ",
      "f(id_space, model='iid', hyper=hyper.iid) + ", extra, paste(cbn, collapse=" + "))),
    data = dat, family = fam,
    control.fixed = list(correlation.matrix = TRUE,
      mean = as.list(setNames(rep(0, length(cbn)), cbn)),
      prec = as.list(setNames(rep(INLA_PREC_PRIMARY, length(cbn)), cbn)),
      prec.intercept = 0.001, mean.intercept = 0),
    control.compute = list(waic = TRUE, config = TRUE),
    control.inla = list(strategy = "simplified.laplace", int.strategy = "eb",
                        control.vb = list(enable = FALSE)), num.threads = 1)
