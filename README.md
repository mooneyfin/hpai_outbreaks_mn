# Associations between Meteorological Conditions, Wild Bird Abundance, and Spillover of Highly Pathogenic Avian Influenza into Poultry Farms: A Daily Time-Stratified Case-Crossover Study in Minnesota, 2022

**Authors:** F. M. Mooney, R. Kowalski, C. Gennings, J. L. Warren, K. A. Lehman, N. DeFelice, S. Pei

---

## Project Description

Daily time-stratified case-crossover study examining how short-term meteorological conditions and wild bird abundance are associated with HPAI spillover into poultry farms across Minnesota in 2022. We use distributed lag nonlinear models (DLNMs) within a conditional logistic regression framework applied to 10 km × 1-day grid cells. Strata are defined by zone × year × calendar month × day-of-week (Lu et al. 2020, PLOS Medicine; Gasparrini 2022, BMC Med Res Methodol).

* Paper: *Submitted to GeoHealth — major revisions resubmission (May 2026)*
* Repository: [https://github.com/mooneyfin/hpai_outbreaks_mn](https://github.com/mooneyfin/hpai_outbreaks_mn)

### What changed in the May 2026 revision

The reviewers requested two structural changes; both are implemented in this branch.

1. **Daily temporal resolution.** Meteorological exposures are now extracted at the day level from ERA5-Land (Nov 15 2021 – Dec 31 2022). Wild bird abundance from eBird Status & Trends remains weekly but is linearly interpolated within each zone between weekly midpoints to produce a smooth daily series. The case-crossover stratum is now `zone × year × calendar month × day-of-week`, with DLNM lag 0–28 days and a natural cubic spline of 4 df on the lag dimension (mirroring Lu et al. 2020).
2. **Explicit sample-size cascade.** A CONSORT-style flow chart documenting how the 110 raw USDA APHIS events become the final analytic sample is generated by `code/model_processing/e_consort_flowchart.R` and saved to `figures/figure_S2_consort_flowchart.{png,pdf}`. Exclusion criteria (spatio-temporal independence at 500 m × 28 d; strata with no valid control day) are surfaced in this figure and in the methods text.

Climate-anomaly z-score work has been moved out of the primary pipeline into `code/data_exploration/climate_anomaly_setup.Rmd` (sensitivity-only).

## 2. Code

Each script sources `create_folder_structure.R` and then `02_code/20_functions/script_initiate.R`, which loads packages, file locations, and shared helpers (including the SPARK Lab figure theme + palettes).

### Data preparation (`02_code/2a_data_prep/`)

Most scripts here require the confidential spillover data and cannot be run as-is. Their outputs are provided as RDS files in `03_output/3b_model_output/`.

* **a_00_era5_land_gee.js** — Google Earth Engine JavaScript editor script. Extracts daily zone × date ERA5-Land for Nov 15 2021 – Dec 31 2022 (primary), plus 1997–2021 weekly climatology baselines for the climate-anomaly sensitivity Rmd.
* **a_00_era5_land_rgee.R** — R-native equivalent using the `rgee` package. Pick whichever tool you prefer; both produce the same daily zone-level CSV.
* **a_01_join_data.Rmd** — Joins spillover events (by `date_confirmed`), daily ERA5-Land, linearly interpolated daily eBird abundance, MPCA feedlots, and NLCD land cover into the 10 km × day fishnet panel.
* **a_02_create_timeseries_df.Rmd** — Computes pairwise event distance × day-gap diagnostics, flags non-independent later events at 200 m / 500 m / 1 km thresholds, and produces the modeling-ready daily timeseries.
* **a_03_create_casecrossover_df.Rmd** — Constructs the time-stratified case-crossover dataset (zone × year × month × DOW), attaches lag 0–28 d exposures, and exports primary + sensitivity variants.
* **a_04_feedlot_bird_abundance.Rmd** — Extracts eBird species-level abundance at feedlot locations using 3 km rasters (21 species: 15 Anseriformes + 6 non-Anseriformes). Author: Rishi Kowalski.
* **a_05_independent_case_confirmation.R** — Validates case independence assumptions.

### Data exploration (`02_code/2b_data_exploration/`)

* **b_00_climate_anomaly_setup.Rmd** *(new in revision)* — Computes 10/15/20/25-year weekly climatology baselines and z-scores. Required input for `c_06_climate_anomaly_models.Rmd` (sensitivity-only).
* **b_01_ebird_mixture_analysis.Rmd** — eBird species mixture analysis via WQS (Figure S1; Table S1).
* **b_02_casecrossover_validation.Rmd** — Leave-one-case-out cross-validation.
* **b_03_climate_anomaly_tests.Rmd**, **b_04_relative_humidity_tests.Rmd**, **b_05_season_model_tests.Rmd** — Exploratory model variants.

### Models (`02_code/2c_models/`)

* **c_00_casecrossover_model.Rmd** — Primary daily DLNM (lag 0–28 d, ns df=4). Produces Figures 3, S3, S5 and Table 3.
* **c_01_lag_sensitivity.Rmd** — Lag-window sensitivity at 14, 28, 42, 56 days.
* **c_02_season_sensitivity.Rmd** — Seasonal stratification (Figures 1, S4; Tables S2, S3).
* **c_03_bird_order_sensitivity.Rmd** — Bird order stratification on the 56-day lag dataset (Anseriformes vs. predators). Figure 4; Table S4.
* **c_04_LASSO_model.Rmd** — Conditional logistic L1 variable selection on lag 0–28 (Figure S6; Table S5).
* **c_05_1km_restriction_sensitivity.Rmd** — 1 km spatial independence restriction sensitivity (Table S6).
* **c_06_climate_anomaly_models.Rmd** — Climate anomaly GAMs using the weekly anomaly panel.

## 4. Sensitivity Analyses (revised)

* **Lag window** — Models at 0–14, 0–28 (primary), 0–42, 0–56 days
* **Seasonal stratification** — Separate spring and fall models
* **Bird order** — Anseriformes vs. predatory birds on the 56-day lag dataset (longer window because Anseriformes migration spans >28 d)
* **Spatial independence** — 1 km and 200 m exclusion radius around cases
* **Variable selection** — Conditional logistic L1 (LASSO) for reduced model
* **Climate anomaly baselines** — 10-year and 25-year reference periods (weekly resolution)

## Methods Summary (daily revision)

**Study design.** Time-stratified case-crossover. For each HPAI case zone-day, control zone-days are sampled from days in the same zone, same calendar year, same calendar month, and same day-of-week. This design self-matches on long-term trend, seasonality, and weekday confounders by construction (Lu et al. 2020).

**Exposure model.** Distributed lag non-linear model (DLNM) with `lag = c(0, 28)`, linear exposure-response (`argvar = "lin"`, per-0.5-SD interpretation retained from the original manuscript), and natural cubic spline on the lag dimension (`arglag = ns(df = 4)`). Estimation: conditional logistic regression via `survival::clogit(..., strata = stratum_id)`.

**Wild bird abundance.** Weekly eBird Status & Trends values are anchored at each MMWR week midpoint and linearly interpolated within zone to produce a smooth daily series. Reported in methods as: "Wild bird abundance was linearly interpolated between weekly eBird Status & Trends midpoints to produce a smooth daily series at each grid cell."

**Independence screening.** Two events are non-independent if they occur < 500 m apart AND within 28 days (primary). Strata are removed only when the sole detection in a case zone-day is the non-independent later event; multi-event zone-days are retained. The 1 km and 200 m thresholds are reported as sensitivity.

**Lag-window extension.** The case-day's lag-28 exposure window for each control day reaches up to 56 days before the case date. ERA5-Land daily extraction therefore runs from Nov 15 2021 through Dec 31 2022 so that all lag windows are fully observed.

## How to Run

1. Download the Zenodo data archive and extract into `data/`, preserving directory structure.
2. (Optional, if rebuilding from scratch) Run `code/data_acquisition/era5_land_gee.js` in Google Earth Engine to regenerate the daily ERA5-Land CSVs.
3. Open `hpai_outbreaks_mn.Rproj` in RStudio.
4. Run any script in `code/models/` or `code/model_processing/` — each script sources `create_folder_structure.R` automatically, which sets up all paths and loads packages.

Pipeline order if rebuilding the analysis-ready objects from raw data:

```
02_code/2a_data_prep/a_00_era5_land_rgee.R          (or a_00_era5_land_gee.js)
02_code/2a_data_prep/a_01_join_data.Rmd
02_code/2a_data_prep/a_02_create_timeseries_df.Rmd
02_code/2a_data_prep/a_03_create_casecrossover_df.Rmd
02_code/2b_data_exploration/b_00_climate_anomaly_setup.Rmd   (sensitivity only)
02_code/2c_models/c_00_casecrossover_model.Rmd
02_code/2c_models/c_01_lag_sensitivity.Rmd   ... etc.
02_code/2d_model_plotting/d_00_table_1.Rmd
02_code/2d_model_plotting/d_04_consort_flowchart.R
```

The data preparation scripts in `02_code/2a_data_prep/` require the confidential spillover data and cannot be run without it.
