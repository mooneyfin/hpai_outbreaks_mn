# Confidential Data

This folder contains georeferenced farm locations of confirmed HPAI spillover events in Minnesota during 2022. 

**This file cannot be shared publicly** It is excluded from both the GitHub repository and the Zenodo data archive.

## File

- `hpai-outbreaks-clean-placeholder-032124.csv` — Cleaned HPAI outbreak records with state, date confirmed, species, herd/flock type, premises ID, and geographic coordinates (lat/lon).
