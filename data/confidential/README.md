# Confidential Data

This folder contains georeferenced farm locations of confirmed HPAI spillover events in Minnesota during 2022. The data include premises identifiers and coordinates provided by the USDA Animal and Plant Health Inspection Service (APHIS).

**This file cannot be shared publicly** due to the confidential nature of individual farm locations. It is excluded from both the GitHub repository and the Zenodo data archive.

## File

- `hpai-outbreaks-clean-placeholder-032124.csv` — Cleaned HPAI outbreak records with state, date confirmed, species, herd/flock type, premises ID, and geographic coordinates (lat/lon).

## How to obtain

HPAI detection records can be requested from the USDA Animal and Plant Health Inspection Service (APHIS). Contact information is available at [https://www.aphis.usda.gov/livestock-poultry-disease/avian/avian-influenza](https://www.aphis.usda.gov/livestock-poultry-disease/avian/avian-influenza). Note that georeferenced premises-level data are restricted and require a data use agreement.
